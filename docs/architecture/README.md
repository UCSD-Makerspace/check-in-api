# Architecture Decision Log

This directory will encapsulate the decisions made based on  [Documenting Architecture Decisions - Michael Nygard](http://thinkrelevance.com/blog/2011/11/15/documenting-architecture-decisions). Each decision should result in a new brief file copied from [this template](template.md).

None of this documentation should EVER be written with generative AI; it is incredibly important that it be a communication between the actual developers that have made decisions in the past to the developers planning the changes of the future.
