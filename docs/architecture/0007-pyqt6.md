# PyQt6

## Status

Accepted

## Context

The current implementation uses Tkinter without a theme and was quite painful to work with. I (Timothy) am unfamiliar with Python UIs though, so this decision is made without a deep understanding of what would be most appropriate here.

## Decision

After poking around for a while I decided on PyQt6 as it seemed to do the things I needed it to (I want it to be able to create simple shapes and text easily to generate things like buttons dynamically as opposed to having to render out full buttons with the text imposed on them like the current implementation uses).
