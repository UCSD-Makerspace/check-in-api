# Move Server to MiniPC

## Status

Accepted

## Context

Up to this point the server has run on a Raspberry Pi 5, which somewhat worked, the primary limiting factor being the Micro SD it used as its boot/storage drive. The random extra Mini PC we had lying around improved this bottleneck factor by several times.

## Decision

Switched from running the backend api on a Raspberry Pi to using a Mini PC.
